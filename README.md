# 保衛羊村 - 自動化輔助工具 (Sheep Village Automation)

本專案提供網頁遊戲《保衛羊村》的 Python 自動化輔助工具，整合 OpenCV 圖像辨識與 PyAutoGUI 模擬操作。

> 📖 **完整圖文取點與操作教學**：請參閱 [詳細操作與使用手冊 (USAGE.md)](./USAGE.md)。

---

## 核心功能

### 1. 敲狼與加速礦 (`wolf_mine_speedup.py`)
- **草地網格覆蓋敲狼**：支援兩點框選草地範圍自動生成網格熱點（或按 `K` 鍵標記），100% 盲敲命中隱藏在木桶內的間諜狼。
- **好友循序巡邏**：自動進入好友家園進行驅趕敲狼與礦山沙漏加速。
- **上限彈窗智慧補刀與自動關停挖礦**：日常點擊確定座標後，若畫面中央出現「今日幫助好友已達上限」的特殊提示彈窗，自動補刀點擊確認並**自動關閉【⚡ 挖礦加速】**，省下後續好友的無效點擊時間。
- **邀請彈窗雙重防護**：到達好友列表末端觸發「暫時不支持邀請好友」彈窗時，支援 **Win32 原生視窗句柄 0.001 秒秒殺**（精準適配 CefFlashBrowser WPF 彈窗與系統對話框）以及**視覺辨識兜底**，自動關閉彈窗並安全停止巡邏。
- **全螢幕標記預覽與文字拖曳**：提供視覺化覆蓋層預覽所有熱點座標，支援直接點擊標籤文字框拖曳微調位置。
- **參數與點位記憶**：所有自訂座標、確定等待延遲、巡邏設定自動保存於 `config.json`，支援全域 `F10` 緊急停止。

### 2. BOSS 自動點擊 (`boss_auto_clicker.py`) 沒在維護!!!
- 針對世界 BOSS 與活動 BOSS 進行高速自動連點與驅趕。

### 3. 升級與自動攻擊 (`upgrade_and_attack.py`) 沒在維護!!!
- 自動辨識可升級之防禦塔並執行升級與攻擊操作。

### 4. 競技場挑戰 (`arena_challenge.py`)
- **雙模式自由切換**：
  - **🛡️ 防守模式**：切磋 ➔ 開始戰鬥 ➔ 動態偵測 ➔ 洗牌翻牌抽獎 ➔ 確定。
  - **⚔️ 進攻模式**：切磋 ➔ 挑戰 ➔ 出戰隊列派狼（全部自動派出 / 指定第 N 隻狼）➔ 開始戰鬥 ➔ 動態偵測 ➔ 洗牌翻牌抽獎 ➔ 確定。
- **狼槽兩點極速生成**：滑鼠移至第 1 隻與第 8 隻狼頭像按 `K` 鍵，自動等分算出 8 格精準座標。
- **雙螢幕 / 多螢幕原生支援**：智慧分析點擊座標，自動鎖定副螢幕設備進行 Windows GDI 硬體截圖辨識。
- **動態戰鬥與二段式洗牌抽獎**：支援勝利（WIN）與惜敗（LOST）自動辨識，並依序執行「點擊卡片觸發洗牌 ➔ 等待洗牌動畫 ➔ 再次點擊翻牌抽獎 ➔ 確定」全自動結算。

### 5. 挑戰好友 (狼 & 防線) (`friend_challenge.py`)
- **🎮 挑戰順序模式**：
  - **🐺➔🛡️ 先狼後防**：先挑戰完所有好友的狼，再挑戰所有好友的防線。
  - **🛡️➔🐺 先防後狼**：先挑戰完所有好友的防線，再挑戰所有好友的狼。
  - **🐺 僅挑戰狼** / **🛡️ 僅挑戰防線**：單項專注挑戰。
  - **🔢 依編號混合**：按好友編號順序由小到大交替挑戰。
- **🖥️ 多螢幕 GDI 智慧截圖**：自動鎖定遊戲座標所在螢幕設備，跨解析度與 DPI 多尺度比對，徹底解決副螢幕辨識問題。
- **⏭️ 右鍵即時跳過**：運行中可隨時「按滑鼠右鍵」或「鍵盤右箭頭」立即中斷並跳過當前好友；防線模式具備自動安全撤防回城機制。
- **🔄 自動換頁與回城重置**：好友跨階段（如第 2 頁切回第 1 頁）自動點擊回家重置列表。
- **🎯 兩點快速標記**：好友 6 位列表與出戰 8 隻狼槽皆支援兩點生成座標。
- **🛡️ 本地圖片隔離保護**：自訂截圖存放於 `images/custom/`，Git 更新永不覆蓋。

## 安裝與環境準備

### 1. 安裝 Python
建議使用 **Python 3.8 ~ 3.11** (64-bit)。

### 2. 安裝相依套件
在專案根目錄下開啟終端機執行：

```bash
pip install -r requirements.txt
```

---

## 快速啟動方式

在 Windows 環境下，直接雙擊對應的 `.bat` 批次檔即可啟動：

- **敲狼與挖礦加速**：雙擊 `start_wolf_mine.bat`
- **BOSS 自動點擊**：雙擊 `start_boss_clicker.bat`
- **防禦塔升級與攻擊**：雙擊 `start_upgrade_attack.bat`
- **競技場防守與進攻**：雙擊 `start_arena_challenge.bat`
- **挑戰好友 (狼 & 防線)**：雙擊 `start_friend_challenge.bat`

或透過指令執行：

```bash
python friend_challenge.py
```

## 操作注意事項

1. **螢幕縮放與解析度**：
   - 支援雙螢幕與多螢幕環境，程式會自動識別並鎖定遊戲座標所在螢幕。
2. **緊急停止與跳過快捷鍵**：
   - 全域緊急停止：按下鍵盤 **`F10`** 鍵立即中斷所有自動化流程。
   - 即時跳過當前好友：在挑戰好友與巡邏時按下**滑鼠右鍵**或鍵盤**右方向鍵 (`→`)**。
3. **圖像辨識閾值**：
   - 預設比對閾值為 `0.9`，若遇辨識不良可於介面微調為 `0.8`。
